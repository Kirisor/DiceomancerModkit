# 战绩（Run History）· 安装说明

给 DICEOMANCER 记录每一局的流水账，并在游戏里回看 —— 类似《杀戮尖塔》的 Run History。
支持**用种子重开一局**（同一个种子 → 同一张地图）。

## 安装

1. 把 `RunHistory.dll` 放进 `<游戏根>/BepInEx/plugins/`
2. 重启游戏

不需要 ModKit 平台，也不需要改任何游戏文件。要卸载就删掉这个 dll，已记录的战绩会保留在
`<游戏根>/BepInEx/RunHistory/` 里。

## 用

进游戏到**桌面**（房间本体），右上角「模组图鉴」牌子下方是「战 绩」。

> 牌子**只在桌面显示**：进图鉴 / 升级 / 选职业 / 小游戏 / 地图 / 战斗中都会自动隐藏，
> 回到桌面再出现（判据是游戏自己的 `SmallGameMainMenu.deskScene` 开关，不是猜场景名）。

- **列表**：一局一行（日期 / 职业 / 进阶 / 连胜 / 结果 / 时长 / 节点 / 收益），8 行一页；
  每行左边有一条结果色条，右下角是翻页。**进阶**是这局选的难度（`—` = 没开进阶或还没结算）；
  **连胜**只在该局获胜时显示它是第几连胜（负/放弃清零，「中断」「进行中」既不计数也不打断）
- **详情**：摘要（职业 · 结果 · 日期 · 种子 · 时长 · 进阶 · 续玩次数 · 收益）+ 路线色块条
  + 卡组 / 遗物 / 统计三个页签
- **悬停高亮**：鼠标放到某张卡或某件遗物上，路线条里会亮起"它是在第几个节点拿到的"
- **结果**分五种颜色：通关 / 阵亡 / 放弃 / 中断（中途退出没走到结算的局）/ 进行中

## 用种子重开一局

- **列表页 →「种子…」**：自建数字键盘输入任意种子（点数字即可）
- **详情页 →「用这局种子重开」**：一键把这一局的种子设为待用

两处都只是写一个「待用种子」（存在 `BepInEx/RunHistory/pending-seed.json`，重启也保留），
下一次在桌面按「开始游戏」时生效，**用掉即自动清除**。

同一个种子生成的地图**完全一致**（章节段落、节点类型、节点之间的连边）。
做这件事要按住游戏里两个随机源：战役种子，以及一个没有播种的静态 `Random`
（后者靠"就地复制 `new Random(seed)` 的内部状态"重置，换实例会被 Mono 内联绕过）。

生效时的日志：

```
战绩：本次开局使用指定种子 123456（原种子已被替换；章节地图将由此种子生成）。
战绩：地图随机源按 seed 123456 重置（地图生成前）｜就地重置=成功｜校验=一致
战绩：Plain 段落挑选｜…｜按种子应取 road#2,road#0,mid#1,mid#0,road#3,road#1（seed 123456）
战绩：地图已生成（新世界）｜ChapterPlain｜段 11 / 节点 45｜指纹 e54ecca5｜明细 maps\…
```

**注意**：种子只固定**地图**。节点里的敌人/剧情挑选还有几处用的是未播种的全局随机，
同一颗种子两次进同一节点遇到的东西可能不同。

## 记录什么

- 开局：种子、时间、职业、起始牌组
- 每个节点：类型、章节、到达时间、本层耗时、血量 / 金币 / 牌数 / 遗物数、这一层新获得的卡与遗物
- 结算：胜负、终局卡组（含升级态）、终局遗物、击杀（普通/精英/首领）、骰子（掷出 1 / 掷出最大 / 掷出最小）、检定成败、钓鱼、被紫雾吞噬、升级币
- 继续游戏按种子归并到同一局，不会多记一条

## 配置

`<游戏根>/BepInEx/config/diceomancer.runhistory.cfg`

| 键 | 默认 | 说明 |
|---|---|---|
| `General.Enabled` | true | 关掉后不装任何钩子，游戏完全不受影响 |
| `General.DataDir` | 空 | 留空 = `<游戏根>/BepInEx/RunHistory` |
| `General.SnapshotNodes` | true | 逐节点快照（路线 / 逐层获取 / 每层耗时都靠它） |
| `Diagnostics.Verbose` | false | 每次落盘与差分的细节 |

## 数据

```
<游戏根>/BepInEx/RunHistory/
  index.json          列表用索引（可删，会自动重建）
  runs/<runId>.json   一局一个文件
  maps/<时间>-<种子>-<章节>.json   每次生成地图的段落/节点/连边转储（最近 80 份）
  pending-seed.json   待用种子（用掉即删）
```

- 纯 JSON，`schema` 字段带版本，手工可读
- **不写游戏存档目录**，不参与 Steam 云同步
- 条数不限；一局约 8~30 KB

## 已知限制

- 面板只在桌面场景显示（战斗里不显示，避免干扰）
- 面板是自建画布，打开时会屏蔽其它 UI 的点击，关闭后恢复
- 旧战绩里引用的 mod 卡/遗物如果被卸载，会显示内部名而不是中文名（数据不丢）
- 种子只固定地图，不固定遭遇与卡序
